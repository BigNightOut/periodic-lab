# Periodic Lab

An interactive periodic table and molecule workbench, packaged as an installable web app (PWA).

- **Explore atoms:** tap an element to see an animated atom (rings or electron cloud), what it's used for, what it bonds with, and Nexus / rocket angles.
- **Build molecules:** put atoms on the bench and drag them together. They bond when both have an empty hand. Yank or hit **Break apart** to pull them apart. Ring view shows the shared electron pairs.
- **Element log:** blue outlines mark elements we've talked about. The list lives in `data/discussed.json` and gets updated from chats.

## Install on Android
Open the site in Chrome, then tap the ⋮ menu and choose **Install app** (or **Add to Home screen**). It opens full screen and works offline.

## Files
| File | What it is |
|---|---|
| `index.html` | The page: table, element cards, atom drawing, layout |
| `bench.js` | The molecule workbench: hands, bonding, physics, ring view, idea cloud |
| `data/elements.json` | 118 elements: PubChem data (public domain) + plain-language cards |
| `data/molecules.json` | 119 molecules/materials with 2D layouts (made with RDKit) and fun facts |
| `data/discussed.json` | Your element log |
| `sw.js`, `manifest.webmanifest`, `icons/` | What makes it installable and offline |

These files are generated by the build scripts in the Claude workspace (`build_elements.py`, `build_molecules.py`, `build_app.py`). Edit the data files directly for small changes.

## Rebuilding the data
`tools/` holds the source: `content/batch_*.json` (element cards), `molecules_src.py` + `molecule_facts.json` (molecules), and the three build scripts. RDKit (BSD-3) is only needed to rebuild molecule layouts.
